# Student Marks Prediction System

Student Marks Prediction System is a Flask web application that uses a
scikit-learn Linear Regression model to estimate student marks from study
hours.

## Project structure

```text
Student-marks-prediction/
??? app.py
??? train_model.py
??? model.pkl                 # Generated by train_model.py
??? requirements.txt
??? templates/
?   ??? index.html
??? static/
?   ??? style.css
??? tests/
    ??? test_app.py
```

## Requirements

- Python 3.10 or newer
- pip

## Setup (Windows PowerShell)

Open PowerShell in the project folder and create/activate a virtual environment:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Install the dependencies:

```powershell
python -m pip install -r requirements.txt
```

## Train the model

Generate the reproducible sample dataset, print the MAE, MSE, and R-squared
evaluation metrics, and save the trained model to `model.pkl`:

```powershell
python train_model.py
```

Run this step before starting the Flask app. The application reads `model.pkl`
from the project directory and reports a clear error if the file is missing.

## Run the web application

```powershell
python app.py
```

Open <http://127.0.0.1:5000/> in a browser. The form accepts study hours from
0 through 10, matching the range of the generated sample data.

The application also provides:

- `GET /health` ? JSON application and model readiness status.
- `POST /prediction` — predicts marks from a form submission. It also accepts
  JSON such as `{"study_hours": 5}` and responds with JSON.

## Run the tests

From the project folder, with the virtual environment activated:

```powershell
python -m pytest
```

The tests cover the home page, health endpoint, prediction response, JSON
prediction, and invalid study-hours input.
